# Preentrega 5 - Sistema de Blog
**Autora:** Paz Lindon
## Descripcion
Este proyecto es un sistema de blog creado en Python.
Permite consultar publicaciones desde la consola.
## Funcionalidades
- Ver todos los posts.
- Buscar posts por titulo.
- Filtrar posts por etiquetas.
- Validar los datos de cada post.
- Salir del programa.
## Organizacion del proyecto
- main.py: archivo principal del programa.
- blog/datos.py: contiene los datos del blog.
- blog/menu.py: muestra el menu.
- blog/operaciones.py: contiene las funciones de busqueda y filtrado.
- blog/validaciones.py: valida los posts.
- blog/__init__.py: identifica el paquete blog.
## Como ejecutar
1. Abrir la carpeta del proyecto en VS Code.
2. Abrir la terminal.
3. Ejecutar el comando:
python3 main.py
## Tecnologias utilizadas
- Python
